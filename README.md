# React Productivity Dashboard

A comprehensive productivity dashboard built with React, Vite, and Tailwind CSS.

## Features

This dashboard includes several tools to help you stay productive:

*   **Todo List:** Manage your daily tasks.
*   **Daily Planner:** Plan your schedule effectively.
*   **Pomodoro Timer:** Use the Pomodoro technique to maintain focus.
*   **Goal Tracker:** Set and track your long-term goals.
*   **Motivation:** Get daily quotes or motivation to keep going.

## Tech Stack

*   [React](https://react.dev/)
*   [Vite](https://vitejs.dev/)
*   [Tailwind CSS](https://tailwindcss.com/)

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

*   Node.js (version 18 or higher recommended)
*   npm

### Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    ```
2.  Navigate to the project directory:
    ```bash
    cd <project-directory>
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

### Development Server

To start the development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

### Building for Production

To build the app for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

### Linting

To run the linter (Oxlint):

```bash
npm run lint
```
